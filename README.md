# PickerFox

Indoor warehouse navigation and search — help pickers find products faster with optimized routes and real‑time location search.

## Overview

PickerFox helps warehouse pickers find any product reliably and quickly. Today pickers frequently need to ask supervisors or search manually, which wastes time and slows the whole operation. PickerFox reduces walking time and confusion by showing an optimized route on a floorplan and giving clear, confirmable pick instructions. Over time we also collect movement data to build a heatmap that highlights fast- and slow-moving products so storage locations can be optimized.

## Product vision

- Fixed rack locations and flexible storage cells can both be managed in the app.
- Pickers follow a digital twin of the warehouse in a map-based interface.
- Managers can activate/deactivate storage spaces, assign product locations, and monitor moving hot spots.
- Heatmaps help reorganize the warehouse to reduce average travel distance over time.

## Goals

- Build a maintainable floorplan using SVG and a clear addressing system.
- Support both fixed rack addresses and flexible storage cells.
- Show an optimized route for each picklist on the floorplan.
- Support optional QR/barcode scanning for audits, storage operations, and location management.
- Provide analytics and heatmaps to improve warehouse layout and product placement.

## MVP

- Upload or edit a floorplan SVG.
- Search product by name or SKU.
- Highlight matching storage spaces on the map.
- Show optimized route to the target locations.
- Quick one-tap picker confirmation, with optional scanning for audits or product placement.
- Admin tools for fixed and flexible storage management.

## Roadmap

1. Finalize warehouse addressing and floorplan design.
2. Build floorplan editor and storage management UI.
3. Add product search and route generation.
4. Add picker confirmation workflow and optional scanning.
5. Add telemetry, heatmaps, and management analytics.
6. Pilot in a warehouse and iterate on UX and data quality.
